# Matching Game

An Android-based memory matching game developed in Android Studio using Kotlin and XML layouts. The game features a grid-based board where players flip cards to find matching pairs, with logic to track attempts and manage game state across turns.

The application emphasizes clean state handling, responsive UI layouts, and clear separation of game logic and presentation. Card flips, match detection, and reset behavior are handled through well-structured Kotlin code, ensuring smooth gameplay and predictable interactions.

This project demonstrates foundational Android development concepts, including activity lifecycle awareness, event-driven UI updates, and state management within a mobile environment.

Technologies Used:
Kotlin · Android Studio · XML Layouts · View Binding · State Management
